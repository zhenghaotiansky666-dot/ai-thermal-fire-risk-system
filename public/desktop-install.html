把指挥端装到电脑上

电脑版和手机版是同一套系统：宽的屏幕会自动变成「左侧导航 + 多列监看卡片墙」， 适合把一台电脑放在值班室或展台当监看终端。下面三种用法按需要选一种。

最快

① 直接用浏览器打开

不需要安装任何东西。用大屏电脑打开下面的地址即可，界面会自动切到电脑布局。

打开电脑版指挥端 直接进监看模式
离线可用

② 下载后一键启动

把整套东西（站点 + 本地服务 + 硬件接收端 + 启动脚本）下载到电脑，解压后双击启动：

  1. 下载源码包（压缩包内已含 启动电脑版.command / 启动电脑版.bat）
  2. macOS 双击 启动电脑版.command，Windows 双击 启动电脑版.bat
  3. 脚本会自动检查环境、构建站点、启动服务，并用独立窗口打开指挥端
git clone https://github.com/zhenghaotiansky666-dot/ai-thermal-fire-risk-system.git
cd ai-thermal-fire-risk-system
./启动电脑版.command        # Windows: 启动电脑版.bat
下载源码包（zip） 打开 GitHub 仓库
像 App 一样

③ 装成独立窗口

想让它看起来像桌面软件（没有地址栏、可放程序坞/任务栏）就用这一招：

  1. Chrome / Edge：打开指挥端 → 菜单 → 保存并分享 → 安装为应用 / 创建快捷方式（勾选“以窗口方式打开”）
  2. Safari：文件 → 添加到程序坞（macOS 14+）
  3. 命令行方式（macOS）：open -na "Google Chrome" --args --app=http://127.0.0.1:4173/mobile-app.html?monitor=1
监看模式

大屏值守怎么用

点右上角 「电脑监看」，左侧导航会收起、内容铺满整屏并进入全屏； 或者在网址后面加 ?monitor=1 直接进监看模式。 设置会记住，下次打开自动保持。

火警时整屏会转红并弹出全屏报警卡，同时把预警推给用户端。

给硬件同学

要改硬件参数从这里入手

端口、上传路由、终审阈值、固件地址都能改，改完刷新页面即可：

  1. public/ai-config.json → hardwarePort 改接收端端口（默认 8787）、visionUrl 改本地 AI 服务地址（默认 8000）
  2. tools/hardware-receiver.mjs → /upload、/upload_thermal 两个路由与终审顺序
  3. tools/local-ai-server.mjs --hardware-port → 本地服务转发给接收端的端口
  4. 详细步骤见仓库里的 docs/硬件同学-编辑指南.md

不会用 git 也可以：下载上面的源码包，改完把你改的文件发回来，我合并。

提示：电脑版和手机版共用同一份数据与同一条链路（局域网中继 / 云端通道）， 所以电脑上报警，手机端会同时响应；反过来手机上报隐患或火源，电脑这边也会立刻看到。
