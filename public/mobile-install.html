iPhone / iPad 安装步骤

描述文件 + 主屏图标
  1. 用 Safari 打开本页（微信内打开请点右上角“在浏览器中打开”）。
  2. 点上面的“iPhone 安装配置文件”，系统提示“此网站正尝试下载一个配置描述文件”，选允许。
  3. 打开 设置 → 通用 → VPN 与设备管理，点“已下载的描述文件 → 安装”（未签名属正常，我们只写入一个主屏快捷方式，不改任何系统设置）。
  4. 回到主屏幕，点新出现的图标即可全屏使用。

不想装描述文件？也可以：Safari 打开页面 → 分享 → “添加到主屏幕”。效果一样。

Android 安装步骤

PWA 网页应用
  1. 用 Chrome 打开上面的页面（扫二维码最快）。
  2. 右上角菜单里选 “安装应用 / 添加到主屏幕”；有的机型会直接弹出安装提示。
  3. 安装后从桌面图标打开，全屏运行、支持离线打开逃生页。

Android 不需要配置文件；如果你们要正式商店版本，可后续用 Android Studio 把同一个网址打成 TWA/APK。

两端怎么互通（云端通道）

不依赖局域网
  1. 系统端顶栏点「链路」→ 点“生成一个新通道”，会得到一串暗号（例如 ntfy:tg-k3f9…）。
  2. 把这个暗号填到用户端的「更多 → 离线联通 → 云端通道」，或让用户端扫这个二维码，两端就配好对了。
  3. 配好之后：系统端拉响警报 → 用户端立刻显示“哪里起火、往哪走”；用户端上报火源 → 系统端弹出横幅并可一键拉响警报。全部走公网，住户手机用移动网络即可。
原型阶段默认用公开的 ntfy.sh 转发（零部署，通道名即暗号，别用真实姓名做通道名）。 正式部署请换成你们自己的中继：仓库里给了两个可直接上线的实现—— tools/relay-server.mjs（Node，可跑在任意云主机/Vercel/Render）与 tools/relay-worker.mjs（Cloudflare Worker 免费额度即可）。 把「云端通道」填成你们的中继域名即可，两端协议完全一致。

极端情况（网络设备损坏、信号被干扰）仍保留兜底：链路面板的“离线事件码”二维码，扫码即可传递火警位置，完全不需要网络。
