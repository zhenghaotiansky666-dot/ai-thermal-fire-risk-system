原文件：`Fire Dector/src/main.cpp`（她们包里的版本）
改好的文件：`outputs/硬件固件修改/main.cpp`（同目录还有 `changes.diff` 可以逐行对照）

> 我只改了地址、端口和注释，**没有动任何业务逻辑与引脚定义**。引脚冲突只标了 TODO，需要她按实际接线确认（我无法验证她们的板子）。

## 一、必须改的 2 处（不改就连不上）

### 1. `thermalServerUrl` 少了端口与路径（原代码就是坏的）

```cpp
// 原来：
const char* thermalServerUrl = "http://10.240.250";          // ← 少了 .12:5000/upload_thermal

// 改成（IP 换成演示电脑的局域网 IP，端口用 8787 以免占用 Mac 的 5000）：
const char* thermalServerUrl = "http://192.168.1.100:8787/upload_thermal";
```

### 2. `serverUrl` 的端口与路径

```cpp
// 原来：
const char* serverUrl = "http://10.240.250.12:5000/upload";

// 改成：
const char* serverUrl = "http://192.168.1.100:8787/upload";
```

**最省事的办法**：在演示电脑上运行

```bash
node tools/hardware-receiver.mjs --port 8787 --print-firmware
```

它会用那台电脑**当前的局域网 IP** 打印好这两行，直接复制粘贴替换即可（这样 Mac 的 5000 端口完全不用动，隔空投送照常用）。

### 3. Wi-Fi 账号密码

```cpp
const char* ssid     = "你的WiFi名称";   // 必须填现场 Wi-Fi
const char* password = "你的WiFi密码";
```

ESP32 只支持 2.4G，手机热点也可以（热点名别用中文/特殊字符）。

## 二、需要她确认的 2 处引脚冲突（我没敢改）

我扫描了 `main.cpp` 里所有 GPIO 定义，发现**同一个 GPIO 被两个功能同时使用**：

| GPIO | 被谁用了 | 冲突点 |
| --- | --- | --- |
| **GPIO 2** | `I2C_SCL`（MLX90640 时钟） + `Y4_GPIO_NUM`（相机数据 D2） | 相机和热像模块抢同一个脚 |
| **GPIO 4** | `SMOKE_PIN`（烟雾传感器） + `Y5_GPIO_NUM`（相机数据 D3） | 相机和烟雾传感器抢同一个脚 |

如果实际板子上这三个外设都能正常工作，说明她的接线与这份代码里的常量不一致（比如相机用了另一套引脚映射）——请她按实物核对一遍；如果确实冲突，症状会是"相机初始化失败"或"烟雾值/热像读数异常"。

我已经在这两行加了 `TODO(引脚冲突)` 注释，方便她搜索定位。

## 三、烧录与验证

1. 用 VS Code + PlatformIO 打开 `Fire Dector` 工程，替换 `src/main.cpp`（或用 `changes.diff` 对照手改）；
2. 先启动电脑端接收端：`node tools/hardware-receiver.mjs --port 8787`（记得放行防火墙的 8787）；
3. 烧录后看串口：
   - `Wi-Fi 已连接！` → 网络通了；
   - 触发时 `红外数据发送成功，响应码: 200` → `/upload_thermal` 通了（这是原来必然失败的路径）；
   - `Windows AI 终审答复: YES/NO` → `/upload` 通了，返回 `YES` 时她的蜂鸣器会响、BLE 广播会打开；
4. 电脑端能看到：观察页 `http://127.0.0.1:8787/` 两张图 + 系统端「监控 → 硬件直连」卡片；
5. 没有硬件时，可以先用 `node tools/hardware-sim.mjs --port 8787 --hot` 模拟她那边发数据。

## 四、为什么端口用 8787（回应"不想动 Mac 的 5000"）

- macOS 的 5000 被系统「隔空播放接收器」占用，关掉它才能用 5000；
- 我们的接收端**默认仍是 5000**（Windows 演示机直接可用），但支持 `--port`：
  - Mac 演示机：`--port 8787`（配合上面的固件两行）；
  - Windows 演示机：`--port 5000`，固件不用改端口；
- 万一口被占，接收端会自动往后找空闲端口，并把"固件该改成哪个端口"打印出来。
